**OpSec Media Studio** — це автономна веб-студія для пресофіцерів, комунікаційників та SMM-фахівців сектору безпеки та оборони. Інструмент об'єднує два критичні етапи підготовки медіаматеріалів в єдиний робочий процес: **надійне знеособлення (OpSec)** та **офіційне брендування для соцмереж і вебпорталів**.

Вся обробка фотографій, включно з роботою штучного інтелекту, виконується **виключно локально у браузері користувача**. Жоден байт даних чи зображень не надсилається на зовнішні сервери.

## ⚡ Ключовий функціонал

### 1. 🛡️ Безпека та цензурування (OpSec)
* **🤖 Автономний AI-детектор облич (MediaPipe):** Швидке локальне виявлення облич із накладанням правильного вертикального овалу (1.35 : 1), який перекриває всю голову разом із зачіскою, вухами, підборіддям та тактичним шоломом.
* **🎲 Захист від AI-реконструкції (Anti-AI Noise):** Генерація псевдовипадкового математичного шуму поверх замаскованих областей для унеможливлення депікселізації нейромережами (Depix тощо).
* **🛠️ Набір інструментів маскування:**
  * 🌫️ Розмиття (Gaussian Blur з плавними межами)
  * 🔲 Пікселізація (Pixelate з регульованим розміром блоку)
  * ⬛ Чорна стрічка з контрастним текстом **«ЦЕНЗУРА»**
  * 🏷️ Тактичні штампи: `OPSEC`, `ДСП`, `🇺🇦`, `🔱 Тризуб`
  * 🖌️ Вільний пензель та довільна кольорова заливка
* **🧹 100% знищення метаданих (EXIF/GPS):** Вбудований бінарний аналізатор інформує про знайдені координати та модель камери, а експорт через перемальовування HTML5 Canvas повністю стирає EXIF, XMP та IPTC мітки.
* **👁️ Режим миттєвого порівняння «До / Після»:** Утримання кнопки або клавіші `Пробіл` для швидкої перевірки необробленого оригіналу перед публікацією.

---

### 2. 🎨 SMM & Офіційне брендування
* **📐 Готові шаблони пропорцій:**
  * `Telegram / Facebook` — Квадрат **1:1** (1080×1080)
  * `Instagram` — Вертикальний формат **4:5** (1080×1350)
  * `Twitter (X) / YouTube Preview` — Горизонтальний **16:9** (1920×1080)
  * `Офіційний сайт ДССЗЗІ` — Фірмовий формат **1600×1200**
  * `Оригінал` — Робота без зміни пропорцій фотографії
* **🏛️ Офіційна айдентика Держспецзв'язку (Векторний SVG):**
  * **Режим сайту:** Автоматично приховує кутовий логотип і розміщує офіційну плашку новин по центру осі X із регульованим відступом знизу.
  * **Режим соцмереж:** Масштабований герб ДССЗЗІ з можливістю розміщення в будь-якому кутку.
* **✍️ Державна типографіка (e-Ukraine):**
  * Підтримка шрифтів `e-Ukraine` та `e-Ukraine-Head`.
  * Автоматичне вирівнювання та перенесення рядків заголовка і підпису.
  * Регульована градієнтна підкладка знизу для гарантованої читабельності білого тексту на засніжених або світлих фото.
* **🔍 Керування композицією фону:** Повзунки Zoom (70–250%), зміщення по осях `X` та `Y`.

## 🚀 Швидкий запуск

Додаток реалізовано у вигляді монолітного вебфайлу, який не потребує збірки (`npm`, `webpack` тощо) чи налаштування бази даних.

### Запуск через локальний веб-сервер (Рекомендовано)
Через політику безпеки браузерів щодо WebAssembly/CORS модулі MediaPipe потребують запуску через протокол `http://` або `https://` (а не напряму через `file:///`).

#### Варіант 1: VS Code
Встановіть розширення **Live Server**, відкрийте файл `index.html` і натисніть:
> `ПКМ` ➔ **Open with Live Server**

#### Варіант 2: Python (термінал)
У папці з проєктом виконайте:
```bash
# Python 3
python -m http.server 8000
```
Відкрийте в браузері: `http://localhost:8000`

#### Варіант 3: Node.js
```bash
npx serve .
```

## 📋 Пам'ятка OpSec (Інформаційна безпека)

1. **Координати та GPS:** Більшість сучасних смартфонів вшивають точні координати зйомки в файл фотографії. Завжди проводьте експорт через студію для гарантованого стирання тегів.
2. **Обличчя та патчі:** Обличчя особового складу та шеврони підрозділів мають бути закриті. Якщо є сумніви щодо розмиття — використовуйте 100% чорну стрічку `ЦЕНЗУРА`.
3. **Обладнання спецзв'язку:** Антени, радіорелейні станції, шильдики техніки, моделі генераторів та кабельні лінії не повинні потрапляти у відкритий кадр.
4. **Документи та екрани:** Категорично заборонено публікувати фото, на яких видно робочі монітори, карти обстановки, позивні чи бланки зі штампом «ДСП».
